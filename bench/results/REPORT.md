## Setup

- 90 seeded instances: sizes 10 tasks / 7 days, 20 tasks / 7 days, 30 tasks / 14 days; load ratio ρ ∈ {0.6, 0.9, 1.15}; 10 seeds each (R54). Capacity counts available slots, each day capped at the daily work limit.
- **Greedy EDF** exactly as R55: earliest deadline first, slot by slot, ignoring focus windows and the min block length; work may run past deadlines.
- **Optimizer**: CP-SAT in strict mode (every deadline is a hard constraint). When strict mode is proven infeasible it switches to minimum total lateness, where the min block length becomes a soft goal (short blocks are counted, as for greedy; D-23). If it ever ran out of time, the app's greedy fallback would be used (the status column of `results.csv` shows it).
- Metrics (R56): deadlines met; total lateness in hours (unplaced work counts as done right after the horizon); preference violations = demanding slots outside focus windows + blocks shorter than the min block length; solve time = wall clock including model building.
